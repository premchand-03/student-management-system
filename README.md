# Student Management System

A web-based Student Management System built using PHP and MySQL.

## 🚀 Features

- Student Login & Logout
- Student Registration
- Add Student
- View Students
- Search Students
- Student Profile
- Edit Student
- Delete Student
- Password Hashing
- Form Validation
- MySQL Database Integration
- Responsive User Interface

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP
- Git
- GitHub

## 📂 Main Modules

| Module | Description |
|---|---|
| Login | Secure student authentication |
| Dashboard | Student management overview |
| Add Student | Create new student records |
| Students | View and search students |
| Profile | View individual student details |
| Edit | Update student information |
| Delete | Remove student records |

## 🔐 Security

- Passwords are stored using PHP password hashing.
- SQL queries use prepared statements.
- User input is validated.
- Database configuration is kept outside GitHub using `.gitignore`.

## ▶️ How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project into `xampp/htdocs`.
4. Create a database named `student_db`.
5. Create the `students` table.
6. Configure local database settings in `config.php`.
7. Open the project in your browser.
