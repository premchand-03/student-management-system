# Student Management System

A web-based Student Management System developed using PHP and MySQL.

## Features

- Student registration
- Student login
- Add student
- View students
- Search students
- Edit student
- Delete student
- Password hashing
- MySQL database integration

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP
- Git & GitHub
